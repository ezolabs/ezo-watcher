# Hostnames the leak gate accepts in this tree: public, structural and documentation names that identify nobody.
#
# One name per line; a name accepts itself and every subdomain of it (`ntfy.sh` accepts `docs.ntfy.sh`).
#   ip:<address>   accepts one IP address (documentation ranges need no entry: they are accepted already)
#   hex:<value>    accepts one long hex run that is data, not a secret (a documented fixture id)
#
# The gate denies every other hostname, so this is the one place to add a public service. A private host, a machine name on
# someone's LAN, a tenant's subdomain or an address that belongs to an owner is exactly what the list must never accept.
